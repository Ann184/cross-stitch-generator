# Cross-Stitch Pattern Generator

Программа для конвертации изображений в схемы для вышивки крестиком.

## Как использовать
1. Положите ваше изображение (например, `pig.png`) в папку с проектом.
2. В файле `main.py` вы можете настроить параметры:
   - `SCALE` — коэффициент сжатия (чем больше число, тем меньше и детализированнее будет схема).
   - `COLORS` — количество цветов в палитре.
3. Запустите скрипт:
   ```bash
   python main.py

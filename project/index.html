Инструкция по работе

  • ЛКМ — поставить крестик.
  • ПКМ — убрать крестик.
  • Shift + ЛКМ — залить всю область текущим цветом.
  • Shift + ПКМ — стереть всю область текущего цвета.
  • Ctrl+Z / Ctrl+Y (или кнопки ↺ / ↻) — отмена и возврат действий.
